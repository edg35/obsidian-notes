> [!quote] 
> "The purpose of computing is insight, not numbers" - Richard Hamming

**Data Science**: is the application of computational and statistical techniques to address or gain insights into a problem in the real world

# Why study data science?

- we are collecting a lot of data
	- google processes more than 20 petabytes of data every day
	- 44 zettabytes of data in the world in 2020
- ~100 trillion tokens of data was used to train GPTs
- We have better and faster machines
- We have better machine learning algorithms/models
- Data is the best way to understand problems and find solutions

# Data Driven AI

- Artificial Neural Networks (ANNs) were introduced in 1943
- Backpropagation algorithm formalized in 1986
- Convolutional Neural Networks (CNNs) proposed in the late 1980s
- ImageNet data set (2009) provided millions of labeled images

- Scale of Training Data for LLMs
	- GPT-3 (2020) Trained on 570GB of text data

# Computational Data Scientist

 - Comp Sci + Data Sci = Computational Data Scientist
 - Interdisciplinary field
	 - Stats
	 - Linear Algebra
	 - AI
	 - Machine Learning
	 - Database
	 - Data Warehousing
- Data Science is explaining the past, using data to understand phenomenon
- Predict the future

# Beyond Accuracy

**Example**: we build DNN model for medical diagnosis, DNN model for traffic recognition, Facial recognition
