## What Is Cloud Computing?

Cloud computing is the **on-demand delivery of IT resources over the internet** with pay-as-you-go pricing. Let’s break this down:

- **On-demand delivery**: Resources are available when needed.  
  Example: Launch 300 virtual servers or use 2000 terabytes of storage instantly with a few clicks. Return them when no longer needed and stop paying immediately.

- **IT resources**: AWS provides products for undifferentiated heavy lifting (e.g., databases, compute, storage) so businesses can focus on unique aspects like data and customizations.

- **Access over the internet**: Resources are accessible securely via web consoles or programmatically, without additional contracts or sales calls.

- **Pay-as-you-go**: Pay only for resources used. For example, avoid paying for developer environments over weekends if they’re not being used.

## Benefits of AWS

### 1. Trade Upfront Expense for Variable Expense
- No need for heavy investment in physical servers or data centers upfront.
- Pay only for the computing resources you consume.

### 2. Stop Spending Money on Data Centers
- Cloud eliminates the need to manage physical infrastructure.
- Focus on applications and customers instead of server maintenance.

### 3. Stop Guessing Capacity
- Avoid over-provisioning or under-provisioning resources.
- Scale in or out based on demand. Example: Launch Amazon EC2 instances when needed.

### 4. Benefit from Massive Economies of Scale
- AWS aggregates usage across millions of customers, resulting in lower pay-as-you-go prices.

### 5. Increase Speed and Agility
- Obtain resources within minutes instead of waiting weeks for hardware.
- Experiment and innovate more efficiently.

### 6. Go Global in Minutes
- Deploy applications with low latency to customers worldwide using AWS's global infrastructure.

## AWS and the Client-Server Model

- **Client**: A web browser or desktop application that makes requests.
- **Server**: Services like Amazon Elastic Compute Cloud (Amazon EC2) respond to those requests.
- Example: A client requests a news article; the server evaluates and returns the article.

### Real-World Metaphor: Coffee Shop
- **Server**: The barista (e.g., Morgan) who fulfills customer requests.
- **Client**: The customer making the request.
- AWS EC2 acts as the "server," validating and responding to client requests.

## Cloud Computing Deployment Models

### 1. Cloud-Based Deployment
- **Description**: Run all parts of an application in the cloud.
- **Use Cases**: 
  - Migrate existing applications to the cloud.
  - Design and build new applications in the cloud.
- **Example**: A company creates an application using virtual servers, databases, and networking components fully hosted in the cloud.

### 2. On-Premises Deployment (Private Cloud)
- **Description**: Resources are deployed on premises using virtualization and resource management tools.
- **Use Cases**:
  - Applications that run on technology fully kept in an on-premises data center.
- **Example**: A company runs legacy applications in its on-premises data center while incorporating virtualization technologies to increase efficiency.

### 3. Hybrid Deployment
- **Description**: Connect cloud-based resources to on-premises infrastructure.
- **Use Cases**:
  - Maintain legacy applications on premises while using cloud for batch data processing or analytics.
  - Meet regulatory requirements by keeping certain data on premises.
- **Example**: A company uses cloud analytics services while keeping legacy applications in its on-premises data center.

## AWS: Pay-As-You-Go Pricing

### Key Concepts:
- Pay for what you use, as you use it.
- Scale resources up or down as needed, avoiding overpayment for unused capacity.
- No pre-payments or upfront contracts required.

- Common, repetitive IT tasks like database setup or backups.
- Allows businesses to concentrate on innovation and differentiation.
