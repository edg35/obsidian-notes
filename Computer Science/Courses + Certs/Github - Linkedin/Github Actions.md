# What is a Github Action?

- easily automation workflows to build, test, and deploy code
- can also assist with code reviews, branch management, and issue management


> [!attention] Security
> You can use your own secrets in github actions hat are stored privately in your github account

# Create first Github Action

```
#Github actions are stored under this folder in the root
/.github/workflows/[action].yml
```
