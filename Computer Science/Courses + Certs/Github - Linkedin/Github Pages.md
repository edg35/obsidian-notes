# Github Pages

- publish a website directly on GItHub from a [[Git]] repository
- The Simplest way to get started: create some HTML files in the root folder of the repo, navigate to the settings of the repo, ad enable GITHub Pages for a branch


> [!note] 
> The Website will be published to username.github.io, followed by the name of the repository. You can however change the url later


- commonly used to publish documentation websites
