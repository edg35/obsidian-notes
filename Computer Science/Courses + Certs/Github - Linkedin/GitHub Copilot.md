# What is Github Copilot?


> [!note] Github Copilot
> AI powered tool that provides code suggestions and portions of code based on the comments or on the context of the file you're editing in that moment. It is th result of a collaboration between Github and OpenAI


- Powered by OpenAi Codex
- GPT-3
- For Copilot, the AI has been trained on billions of lines of code from public repositories on Github
