# What is [[Git]]?

- Git is a version control system that allows you to track changes you or your coworkers make over time
- With Git, you are able see history over time and roll back to a previous version in seconds

Branch: A copy of your source code that you can edit without making changes to the original file
Merge: An operation that synchronizes your branch with another one


# What is Github?

- A online service where developers work together
- A cloud based storage service to store code and share with others
