In data structures, a **node** is a fundamental element used to build various complex structures like linked lists, trees, and graphs. Each node typically contains two main parts:

1. **Data**: The value or information that the node stores.
2. **Links/Pointers**: References to other nodes in the structure, allowing the nodes to be connected in a particular arrangement.

### Types of Nodes in Different Data Structures:

- **[[Linked List]] Node**: Contains data and a pointer to the next node in the list.
- **[[Trees]] Node**: Contains data and pointers to its children (e.g., left and right children in a binary tree).
- **[[Graph]] Node (Vertex)**: Contains data and may have pointers to other nodes (neighbors) connected by edges.

Nodes are the building blocks that define the structure and relationships within a data structure, making it possible to traverse, search, and modify the data efficiently.
